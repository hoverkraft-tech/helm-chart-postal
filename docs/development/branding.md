# Project visuals

The project logo and social preview use the official
[Hoverkraft project template and wordmark](https://github.com/hoverkraft-tech/branding/tree/main/brand/identity/logos),
with project-specific vector symbols. Colors and typography follow the
[brand identity](https://github.com/hoverkraft-tech/branding/tree/main/brand/identity).

The editable sources are `.github/logo.svg` and `.github/social-preview.svg`.
Use `.github/social-preview.png` for the repository's GitHub social preview setting.
Keep the official wordmark proportions and the clear space around it.
